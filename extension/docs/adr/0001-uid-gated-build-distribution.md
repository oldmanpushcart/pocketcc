# 构建期按 UID 出授权包

工具只在熟人之间传，早期用「构建期把 `sha256(salt+uid)` 内联进产物、运行期三处比对」做到一人一包、转发无效：不认识的 UID 起不来。

作废理由：判定跑在客户端，认真要绕的人一定绕得开，它真正约束的只有朋友的使用体验（每发一版都要按人出包、各人的包还不能互发）；而防转发售卖，靠启动时的署名与「免费分享、请勿售卖」告知比靠哈希更有效。2026-11 起改为一份包所有人通用 + 署名告知页（原授权页只剩告知职责），准入三闸与构建期 `--uid/--friend/--salt` 参数面一并删除。
